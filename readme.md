# 🥚 Calculadora de Huevos 

Una aplicación práctica desarrollada en Python para automatizar y escalar el cálculo de huevos en función del tamaño del molde y el tipo de bizcocho elegido.

### Contexto y Caso de Uso Real

En la repostería, cambiar el tamaño de un molde o adaptar una receta a diferentes diámetros/alturas requiere cálculos proporcionales precisos para evitar que el bizcocho quede desbordado o demasiado bajo.

Esta herramienta nació para solucionar un problema real en el flujo de trabajo diario de una pastelería, eliminando la necesidad de hacer cálculos manuales antes de cada horneado, reduciendo el margen de error y los desperdicios en la preparación de recetas.

---

### Características Principales

* **Escalado Proporcional:** Ajuste automático de cantidades según el molde seleccionado.
* **Optimizado para Recetas de Repostería:** Cálculo exacto de huevos y secos por unidad de volumen.
* **Interfaz Fácil de Usar:** Diseñada para una consulta rápida durante la jornada.

---

### Tecnologías Utilizadas

* **Lenguaje:** Python 3
* **Librerías:** Streamlit

---

### Cómo Ejecutar el Proyecto

1. **Clonar el repositorio:**

```bash
git clone [https://github.com/matheuslourenci/Calculadora_Huevos.git](https://github.com/matheuslourenci/Calculadora_Huevos.git)
cd Calculadora_Huevos
```

2. **Instalar librería:**

```bash
pip install streamlit
```

3. **Ejecutar la app:**

```bash
streamlit run app.py
```
